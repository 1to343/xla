# prompts.md — все промпты для Claude Code

Копируй промпт целиком и вставляй в Claude Code. Где написано **[ВСТАВЬТЕ...]** —
подставь своё. Все работают по очереди на одном ноутбуке, файлы никуда передавать
не нужно — они уже в одной папке.

> Подсказка: если в папке лежит `CLAUDE.md`, Claude уже знает контекст проекта,
> поэтому промпты можно вставлять как есть.

## День 1 — Фундамент

Порядок работы: У2 → У4 → У1 → У5 (У3 — набросок на бумаге, без ноутбука)

### У2 — Исследование
```
Ты помощник в школьном проекте. Тема: в России не хватает специализированных MES/ERP-систем для производства микрочипов.

Собери информацию и сохрани в файл research.md:
1. Что такое MES и ERP простыми словами (по 2-3 предложения).
2. Какие российские ERP и MES уже есть (названия, кратко).
3. Почему обычные ERP/MES плохо подходят для завода микрочипов (особые задачи: учёт пластин-wafer, контроль выхода годных кристаллов, управление рецептами техпроцесса).
4. Какие заводы микрочипов есть в России (названия).
5. Вывод: в чём именно пробел, который мы хотим закрыть.

Пиши простым языком для 8 класса, к каждому факту давай источник. Сохрани в research.md.
```

### У4 — Старт прототипа — ГЛАВНАЯ ЗАДАЧА ДНЯ
```
Создай рабочий прототип-демо веб-интерфейса MES/ERP-системы для управления производством микрочипов (школьный проект).

Сделай ОДИН файл index.html (HTML + CSS + JavaScript внутри, без внешних библиотек), открываемый в браузере. Требования:
- Весь интерфейс на русском, современный аккуратный дизайн, читаемые шрифты.
- Слева меню: Дашборд, Партии пластин, План производства, Контроль качества, Склад.
- Дашборд: карточки с цифрами (заказов в работе, партий пластин, средний выход годных %, загрузка оборудования) и простой график.
- Партии пластин: таблица (номер партии, тип чипа, этап, статус, дата), 6-8 строк примерных данных.
- План производства: таблица заказов с прогрессом выполнения.
- Контроль качества: показатель выхода годных кристаллов по партиям.
- Переключение разделов по клику в меню на JavaScript, без перезагрузки.
- Заполни реалистичными данными про микрочипы.

Чтобы выглядело «живым» и презентабельным. Сохрани как index.html.
```
