## Как работать с одним ноутбуком

Всё просто: файлы лежат в одной папке на ноутбуке. Никакого git не нужно.

**Главное правило:** передавая ноутбук следующему — убедись, что все файлы сохранены.

### Порядок работы
- Смотри `prompts.md` — там написано, кто что делает в каждый день и в какой очерёдности.
- Каждый участник: открыл нужный файл, выполнил свою задачу через Claude Code, сохранил — передал ноутбук следующему.
- Если работаете параллельно (кто-то без ноутбука) — готовьте материал на бумаге или в голове, потом вносите в файл.

### Резервная копия
В конце каждого дня копируйте всю папку проекта на флешку или в облако (Яндекс.Диск и т.п.) — на случай если что-то случится с ноутбуком.

## Как смотреть результат

- `index.html` (прототип) и `slides.html` (презентация) — **открываются двойным
  кликом** в браузере (Chrome, Edge). Интернет не нужен.
- Презентация листается **стрелками** на клавиатуре (← →).
- Остальные файлы `.md` — это текст, открываются любым редактором.
